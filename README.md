# React Playground

A collection of small interactive applications developed to practice React, component-based architecture, and fronted development concepts.

## About

This project was created as a learning environment for experimenting with React and Tailwind and building small interactive tools.

The applications are accessible through a shared navigation menu, with components organized into separate folders for each tool.

The source code also includes learning notes and comments documenting concepts explored during development.

## Applications

#### Tic-Tac-Toe

A simple interactive Tic-Tac-Toe game build to practice component interactions, state management, and user events.

#### Calculator

An experimental calculator created to explore user input handling and application logic.

**Status:** Incomplete

#### Stopwatch

A simple stopwatch developed to practice time-based interactions and state updates.

**Status:** Incomplete

## Technologies

- React
- JavaScript / TypeScript
- HTML5
- CSS3
- Tailwind

  ## Project Structure

  The application is organized into shared components, such as the home page and navigation menu, and separate component folders for individual tools.

  This structure allows each application to be developed independently while sharing a common interface.

  ## Status

  **Learning Project** - A collection of experiments and exercises created while learning React. Some applications are incomplete, and further development is not currently planned.
